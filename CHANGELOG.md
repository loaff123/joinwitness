# Changelog

## 0.1.0 — 2026-09-30

Initial source release under MIT. No PyPI publication is implied.

### Release scope

- Local CSV join preflight for inner and left equality joins
- Single and composite exact-text keys, explicit NULL literals, and strict UTF-8 CSV parsing
- Declared relationship validation and exact predicted row counts
- Duplicate and unmatched key statistics, expansion groups, and optional quality thresholds
- Exact left-side amount reconciliation with signed and absolute repeated contributions
- Self-contained offline HTML and deterministic JSON reports
- Privacy-default report exports, with bounded raw key samples only when requested
- Reusable audit configuration and a synthetic demonstration command
- English and Simplified Chinese getting-started guides, semantics, privacy, security, and comparison documentation

### Release qualifications

Record actual local/CI verification and measured benchmark results separately. A configured workflow does not establish that it has run on Windows or any other platform.
